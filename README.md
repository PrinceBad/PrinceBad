## [01] SYSTEM OVERVIEW

I build **privacy-first, hardware-aware software**—bridging low-level PC and mobile device internals with on-device AI, hybrid retrieval pipelines, and fault-tolerant Python tooling. From bare-metal diagnostics and bootloader workflows to quantized mobile LLMs, my focus is simple: run compute locally where practical, design for real-world network and filesystem failures, and ship utilities that hold up under everyday use.

- 📱 **On-Device & Edge AI:** Offline Android apps built with Kotlin and Jetpack Compose, leveraging LiteRT, Vulkan GPU delegates, and real-time camera OCR.
- 🔧 **Firmware, Mobile & Systems Labs:** Custom Android ROM and kernel deployments, Linux mobile OS testing (PostmarketOS / Ubuntu Touch / Termux), and DNS-level network filtering (Pi-hole / AdGuard).
- 🛡️ **Applied AI & Hybrid Retrieval:** Search pipelines pairing lexical (BM25) and dense embeddings with prompt-injection defenses and structured evaluation.
- ⚙️ **Fault-Tolerant Automation:** Zero-dependency provisioning scripts, concurrent media pipelines, and reversible filesystem tools with dry-run previews and rollback manifests.
